# 機能紹介

shovel の主な画面と機能を、スクリーンショットとあわせて紹介する。
設計の詳細は [design/](./design/) を参照。

> スクリーンショットはデモ用のプロジェクト（`todo-api`）で撮影したもの。
> エージェントの応答内容はデモ用で、実際のエージェントの出力ではない。

## プロジェクト一覧

![プロジェクト一覧](./images/01-project-manager.png)

起動すると最初に開く画面。1 プロジェクト = 1 サンドボックス。

* フォルダを指定してプロジェクトを作成する
* サンドボックスの状態（実行中／停止中）を表示する
* プロジェクトを開くと、プロジェクトごとのウィンドウが開く
* 「詳細」から、サンドボックスの診断や、プロキシに拒否された通信の確認・許可ができる

## チャット

![チャット画面](./images/02-chat.png)

サンドボックスの中で動く AI エージェントと ACP で対話する、メインの画面。

* 1 タブ = 1 セッション。タブは最大 10 個まで同時に開ける
* エージェントのプラン、ツールの実行（読み込み・検索・編集・コマンド実行）をそのまま表示する
* 返答は Markdown（表・コードのハイライト・Mermaid の図）で表示する
* 返答に含まれる選択肢（`- [ ]`）はチェックボックスになり、選んでそのまま送信できる
* Mode・Model の切り替えと、トークン使用量を入力欄の下に表示する
* `/` でスラッシュコマンドを補完する
* 会話は履歴として残り、あとから再開できる

## 差分の表示

![差分ビュー](./images/03-diff.png)

エージェントがファイルを編集したときは、ツール実行の行の「差分を表示」から変更内容を確認できる。

* 左右表示と 1 列表示を切り替えられる
* 変更された行の中で、単語単位の違いを強調する

## ファイラーとエディタ

![Markdown エディタ](./images/04-markdown-editor.png)

左側のファイラーでプロジェクトのファイルを扱う。

* フォルダ・ファイルの作成、名前の変更、削除（OS のゴミ箱へ移動）、ドラッグ & ドロップでの移動
* ファイル名と中身をまとめて検索する
* ファイルをエージェントへの「コンテキスト」として添付できる

テキストファイルは、ダブルクリックでタブとして開いて編集できる。

* Markdown・HTML はソースとプレビューの分割表示
* 自動保存。エージェントと同時に編集して衝突したときは、上書きせずに別名のコピーを残す
* Markdown は「印刷用表示」から印刷・PDF 化できる

![Mermaid のプレビュー](./images/05-mermaid-preview.png)

* Mermaid（`.mmd`）は図をプレビューする。拡大・縮小・ドラッグでの移動ができる
* JSON・YAML・CSV・画像なども、それぞれに合った表示で開ける

## 分割ビュー

![分割ビュー](./images/07-split-view.png)

タブの領域を左右に最大 4 つのペインに分けて、チャットを見ながら仕様書を書いたり、ファイル同士を見比べたりできる。

* タブを右クリックして「右に分割して移動」すると、そのペインが半分に分かれ、タブが右の新しいペインへ移る
* 各ペインが自分のタブバーを持ち、タブはドラッグでペインの間を移せる
* ペインの境目はドラッグで幅を変えられ、ペインの構成と幅は次に開いたときも元に戻る

## ブラウザ

![ブラウザのタブ](./images/08-browser.png)

アプリの中のブラウザのタブで Web ページを開ける。ドキュメントを分割ビューでチャットの横に並べて、見ながらエージェントに指示できる。

* 戻る・進む・再読み込み、アドレスバー（URL のほか、語句を入れると検索）、ページ内検索
* ブックマークはプロジェクトごと。左の「ブラウザ」パネルから開く・追加・編集・削除できる
* ログイン状態はアプリ全体で共通で、次に起動したときも残る
* ブラウザはホスト側で動き、エージェントからは操作できない
* ページの右クリックから、選択した文字の引用・URL・スクリーンショットをチャットに渡せる

## 画像の注釈

![画像の注釈](./images/09-image-annotation.png)

スクリーンショットなどの画像に印や文字を書き込んで、「この画面のここ」をエージェントに伝えられる。

* ブラウザのページを右クリックして「スクリーンショットに注釈を付けてチャットに添付」を選ぶと、撮った画像をすぐに注釈の画面で開ける。「保存して添付」でそのままチャットに添付する
* ファイラーで開いた画像は、左上の「注釈を付ける」から同じ画面を開ける
* 矩形（角丸）・楕円・矢印・文字を書き込める。色は 7 色、太さは 3 段階、線は実線・破線・点線から選べる
* モザイクで個人情報などを隠せる。細かさは 3 段階で、隠していることが一目で分かる
* 切り抜きで、必要な範囲だけを保存できる
* 書き込んだものは、保存するまでは選んで移動・大きさの変更・削除ができる。元に戻す／やり直すにも対応
* 元の画像はそのまま残し、注釈を付けた画像は別のファイル（`〜-annotated.png`）として保存する

> モザイクがかかるのは保存した画像だけで、元の画像はプロジェクトに残る（サンドボックスの中のエージェントからも読める）。
> 隠したい情報が写っている場合は、元の画像を削除する。

## 権限の確認とテーマ

![権限確認カード（ダークテーマ）](./images/06-permission-dark.png)

エージェントがコマンドの実行などで許可を求めたときは、チャットにカードを表示する。

* 「常に許可」「許可」「拒否」から選ぶ
* 裏のタブで許可を待っているときは、タブにバッジを表示する

エージェントが選択肢付きで聞き返してきたとき（Claude Code の AskUserQuestion など）は、
チャットに質問カードを表示する。

* 選択肢を選ぶ・自由記述で答えるなどして「送信」する
* 「回答しない」で答えずに続けてもらう、「中止」でその作業をやめてもらうこともできる

安全のための仕組みは次の 3 段で構成されている。

1. **サンドボックスによる隔離** — エージェントの実行・ファイル編集はサンドボックスの中で完結する
2. **権限の確認** — 上のカードで、操作ごとに許可を決める
3. **Mode** — エージェントの動き方（確認の頻度など）をユーザーが選ぶ

その他

* ライト／ダークテーマ、言語、文字サイズ、送信キーを設定で変更できる
* サンドボックス内でコマンドを実行するパネル（ターミナル表示にも対応）
